# Facebook Messenger App Clone

This project is a Facebook Messenger clone that I created while following a Git tutorial. It was built as a hands-on way to practice using Git and GitHub while working on a realistic messaging application interface.

The app is inspired by Facebook Messenger’s core chat experience, including conversation-based messaging, a clean and familiar layout, and an interface designed to resemble a modern social messaging platform. Building this clone helped me understand how a larger application can be developed and tracked over time through commits, branches, and version control workflows.

Throughout the project, I used Git to save progress, manage changes, and better understand how developers collaborate on software projects. This repository represents both the finished Messenger-style app and my learning journey with Git.

## Features

- A Facebook-style home page and responsive user interface.
- A social feed for displaying posts from users.
- Create, view, and interact with posts.
- Like, comment on, and share post concepts.
- User profile and navigation areas inspired by Facebook.
- Messenger-style chat functionality for conversations between users.
- A layout that works across desktop and mobile screen sizes.
- Reusable components to keep the interface consistent and easier to maintain.

## Technologies Used

The exact stack may grow as the application develops, but this project uses common modern web-development tools such as:

- **HTML** for the page structure and content.
- **CSS** for styling, responsive layouts, colours, spacing, and visual design.
- **JavaScript** for interactive features and dynamic user-interface behaviour.
- **Git** for version control and tracking the history of the project.
- **GitHub** for storing the repository and sharing project progress online.

Depending on future requirements, the project may also use a front-end framework such as React, a back-end service, a database, authentication, or cloud storage for user-generated content.

## What I Learned

Working on this clone has helped me practise more than just building a user interface. It has also given me experience with organising a project, breaking a large application into smaller features, and improving code step by step.

Some of the areas I am learning include:

- Creating clear and responsive page layouts.
- Designing interfaces that are easy to navigate.
- Writing maintainable HTML, CSS, and JavaScript.
- Building and reusing interface components.
- Using Git commands to add, commit, review, and manage code changes.
- Understanding how GitHub repositories support collaboration and project history.

## Project Goals

My goal is to continue developing this Facebook clone into a more complete social media experience. Future updates may include user authentication, real-time messaging, post comments, notifications, friend requests, profile editing, image uploads, and a persistent database.
